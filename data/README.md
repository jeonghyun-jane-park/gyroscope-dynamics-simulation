# Experimental data

The MATLAB analysis expects an experimental CSV named:

`ExportedData - Run 2.csv`

The source script reads the following columns:

- `Acceleration - x (m/s²) Run 1`
- `Acceleration - y (m/s²) Run 1`
- `Acceleration - z (m/s²) Run 1`
- `Angular Velocity - x (rad/s) Run 1`
- `Angular Velocity - y (rad/s) Run 1`
- `Angular Velocity - z (rad/s) Run 1`

The raw CSV was not included in the files used to assemble this repository package, so it is intentionally not fabricated here. Add the original experimental export if you have permission to publish it. If the data should remain private, keep it local; `*.csv` is ignored by the repository `.gitignore`.
